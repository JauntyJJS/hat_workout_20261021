Understanding gtsummary object

We can now work on customising the table itself. To do this, we need to understand more about the gtsummary object.

Every gtsummary object is a list comprising of, at minimum table_body, table_styling. Here is how you can extract table_body and table_styling and print the header_names.

  • table_body
  • table_styling
  • header_names

Click on the different tabs.

table_body object is the data frame that defines what gets printed as the output. The compulsory columns are variable, row_type and label. label depicts what is printed at the Characteristic column. stat_1 depicts what is printed at the Control column. stat_2 depicts what is printed at Treatment column. p.value is printed at the p-value column.

table_styling objects is a list of data frames containing information about how table_body is printed, formatted and styled.

gtsummary::show_header_names() prints the header/columns= names as text to the console.
