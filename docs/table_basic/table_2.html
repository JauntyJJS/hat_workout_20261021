Exercise (Table Creation)

In this exercise, we create the pregnancy duration and birth weight summary table.

Ensure that

  • The labels are set correctly,
  • Duration of pregnancy categories are displayed as count (percentage) with counts as integers and percentage in one decimal place.
  • Total birth weight is displayed as mean ± standard deviation in integers without big marks.
  • Birth weight categories are displayed as proportion (percentage) with proprtions as integers and percentages in one decimal place.
  • Fisher Test is done on pregnancy duration groups.
  • Wilcox Test is done on total birth weight.
  • Chi Square Test without Yates’ continuity correction is done on birth weight categories.
  • p values are displayed in two decimal places.
  • Variable group header are added for both pregnant duration and birth weight.
  • footnotes are removed.
NoteHint 1

Ensure the label parameter is something like this

label = list(
      "Preg_duration_32" ~ "<32 wk",
      "Preg_duration_35" ~ "<35 wk",
      "Preg_duration_37" ~ "<37 wk",
      "Birthweight" ~ "Total weight - g",
      "Birthweight_2500" ~ "<2500 g - no./total no. (%)",
      "Birthweight_1500" ~ "<1500 g - no./total no. (%)"
    )

Exercise (Change >0.99)

We have done this before in the previous section. Ensure that

  • pvalue_fun = gtsummary::label_style_pvalue(digits = 2) is replaced with pvalue_fun = p_value_style in the function gtsummary::add_p.
  • p_value_style returns 1.0 when if p value is 1.
  • p_value_style returns gtsummary::style_pvalue(x, digits = 2) otherwise.
NoteHint

Ensure the p_value_style function is something like this

p_value_style <- function(x) {
  dplyr::case_when(
    x == 1 ~ "1.0",
    .default = gtsummary::style_pvalue(x, digits = 2)
  )
}
